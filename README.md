# RECICLA ELETRONICO PAULISTA ♻
## Um sistema em prol do meio ambiente 🍃🌳
O Recicla Eletrônico Paulista (REP) é uma **plataforma** que visa facilitar o descarte correto de resíduos eletrônicos nas mesorregiões do estado de São Paulo, conectando **usuários a pontos de coleta e receptores**.

Desenvolvido com base no Design Thinking, o REP utiliza tecnologias como **JavaScript, HTML, CSS e PHP** para criar um sistema intuitivo e seguro.

Com uma abordagem sustentável, o **Recicla Eletrônico Paulista** busca reduzir os impactos ambientais do descarte inadequado, promover a conscientização da população e estimular a reciclagem. Espera-se que a iniciativa gere um impacto positivo ao aprimorar a gestão de resíduos eletrônicos e contribuir para um meio ambiente mais limpo.

### Funcionalidades do sistema ♻🛠
* **Tela inicial**:
    * Apresentação do REP;
    * Classificação das **categorias** de resíduos eletrônicos;
    * Passo a passo de como se **cadastrar** no sistema;
    * Seção de **impactos** causados pelo descarte **irregular**;
    * Seção dos **benefícios** do descarte **correto**;
    * Recomendações para realizar um **descarte seguro e eficiente**;
    * Estatísticas sobre o **descarte irregular** de resíduos eletrônicos;
* Tela de cadastro **[descartador e receptor]**;
* Tela de login **[descartador e receptor]**;
* Perfil **descartador**:
    * Conferência de dados pessoais
    * Histórico de descartes;
    * Acesso ao mapa dos pontos de descarte.
* Perfil **receptor**:
    * Conferência de dados sobre o ponto de descarte;
    * Histórico de descartes naquele ponto de descarte;
    * Postagem de novos registros de descarte.
* Mapa dos pontos de descarte dentro das **mes
sorregiões** do Estado de São Paulo;
